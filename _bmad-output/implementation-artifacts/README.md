# Implementation Artifacts

Các spec/review cũ đã được lưu trữ tại [`../archive/`](../archive/) để tránh agent
tự động đọc lại làm tràn token context. Lịch sử đầy đủ nằm trong git history.

Khi tạo spec mới cho một tính năng đang triển khai, đặt file ở thư mục này và
chuyển xuống `../archive/` ngay sau khi tính năng được merge.
